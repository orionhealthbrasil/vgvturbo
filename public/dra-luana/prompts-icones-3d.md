## Estilo-base (repetido em todo prompt — não editar)

3D icon render in a soft glossy clay/glass style, like a premium modern
app icon. Rounded-square badge shape (like a squircle), front-facing
isometric-friendly angle, subtle bevel on the edges, warm soft studio
lighting from the top-left with a gentle specular highlight, faint soft
drop shadow beneath the object only (no background scene, no floor, no
extra props). Material reads as polished ceramic / frosted glass —
smooth, matte-to-glossy gradient, not plastic-shiny, not metallic. Color
palette strictly limited to these brand colors: mustard gold #CCBA6D,
olive green #796B2D, muted gold-olive #AFA86C, pale sage green #E5EFDA,
light cream #F8F6D6, cognac brown #7D6235. No blue, no neon, no bright
saturated colors outside this palette. No text, no letters, no numbers,
no watermark. Transparent PNG background. Square 1:1 composition, high
resolution.

**Regra de dominância do objeto (importante):** the main subject must be
an instantly recognizable, solid, chunky 3D object — like a single toy or
gem sitting on the badge — filling at least 55–65% of the badge's width.
Do NOT render it as a thin outline, a flat 2D icon, or an abstract
squiggle/wave/flame/ribbon shape. If the subject has two parts (e.g. an
object plus a small secondary symbol), the main object must clearly
dominate the frame and the secondary symbol must be visibly smaller and
secondary, never the same size or competing for attention.

## 4. Distúrbios metabólicos — `disturbios-metabolicos.png`

[cole o parágrafo de estilo-base acima] + Subject: one single laboratory
